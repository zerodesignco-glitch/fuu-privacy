プライバシーポリシー

最終更新日: 2026年10月9日

fuu.(以下「本アプリ」)は、利用者の個人情報を収集しません。

記録した内容は、お使いの端末の中だけに保存されます。本アプリは独自のサーバーを持たず、開発者を含む第三者がその内容を見ることはできません。

1. 収集しない情報について

本アプリは、以下のいずれも収集・送信しません。開発者のサーバーに保存することもありません(本アプリは独自のサーバーを持ちません)。

  • 氏名、メールアドレス、電話番号などの連絡先情報
  • アカウント情報(本アプリはアカウント登録を必要としません)
  • 気分の記録、タグ、メモ、誕生日、住んでいる地域など、利用者が入力した内容
  • 位置情報、連絡先、写真、カメラ、マイクなどの端末データ(本アプリにはこれらを扱う機能がありません)
  • 広告識別子(IDFA)、その他の追跡用識別子
  • 利用状況の分析データ、クラッシュログ

広告および解析用の SDK も組み込んでいません。利用者が入力した内容は、第2節のとおり端末内にのみ保存されます。

2. 端末内に保存する情報

本アプリは、次の情報を端末内のアプリ領域にのみ保存します。クラウドへの自動同期は行いません。

  • 記録(日付、気分、場所、相手、できごと、ことば、メモ)
  • 利用者が追加したタグ
  • 任意で入力する誕生日(月日のみ。年は保存しません)と住んでいる地域(8つの地方から選択。位置情報は使いません)。その日に「ふう」がかけるひとことを選ぶためにだけ、端末内で使います
  • 設定(リマインダー、表示、かぎ)と、初回の案内を表示したかどうかの印
  • 有料プラン「fuu. Plus」の加入状態の写し(有効かどうか、プラン、有効期限)

このアプリ領域は、iCloud やパソコンへのバックアップの対象外に設定しています。そのため、バックアップからの復元や機種変更の際には、通常は引き継がれません(ただし、この除外は iOS の仕様上、確実に保証されるものではありません)。本アプリを削除すると、これらの情報も端末から削除されます。

3. 書き出しと削除

  • 書き出し: 画面右上の歯車から開く「せってい」の「あなたのデータ」にある「記録を書き出す (JSON)」で、記録を JSON ファイルとして書き出せます。ファイルに含まれるのは記録と書き出した日時だけで、誕生日・地域・設定は含まれません。保存・共有先は利用者が選び、選んだ先での取り扱いはその提供事業者のポリシーに従います。書き出しのたびに、アプリのキャッシュ領域に控え(fuu-log.json)が作られ、次の書き出しで上書きされるか、iOS がキャッシュを整理するか、本アプリを削除するまで残ります。現時点では、書き出したファイルをアプリに読み込む機能はありません。
  • 削除: 記録は1日単位で、または「あなたのデータ」の「すべての記録を削除…」で一括して削除できます。削除した記録は元に戻せません。一括削除で消えるのは、記録と利用者が追加したタグです。誕生日・地域・設定・加入状態の写し・書き出しの控えは残ります。地域は選んだ地方をもう一度押すと外せますが、誕生日は現在アプリ内では変更のみで、消すことはできません。端末内の情報をすべて消すには、本アプリを削除してください。

4. 通知について

リマインダー通知は端末内で完結するローカル通知です。通知のためのプッシュトークンの発行・送信は行わず、通知の文面に記録の内容は含まれません。通知機能は初期設定でオフになっており、利用者が有効にした場合のみ動作します。

5. かぎ(Face ID / Touch ID / パスコード)について

「fuu. Plus」をご利用中の方が「せってい」の「かぎ」をオンにすると、本アプリを起動するときに iOS の Face ID / Touch ID(またはパスコード)で本人確認を求めます。認証は iOS が端末内で行い、本アプリは成否の結果だけを受け取ります。顔や指紋などの生体情報を、本アプリが取得・保存・送信することはありません。

6. 通信と有料プランについて

本アプリが通信する相手は Apple(App Store)だけで、目的は有料プラン「fuu. Plus」(自動更新サブスクリプション。月額と年額)のためです。

  • 加入の有無にかかわらず、本アプリを起動するたびに、Apple の StoreKit を通じて有効な購読があるかを確認し、完了していない購入があればその処理を完了させます
  • 加入画面を開いたときは、価格と無料お試しの対象かどうかを取得します
  • 購入や購入の復元を行ったときは、そのために通信します

本アプリが渡すのは商品の識別子など購入に必要な情報だけで、記録の内容は含まれません。開発者のサーバーや Apple 以外の中継サービスは使いません。お支払い情報は Apple が管理し、開発者がクレジットカード番号などを受け取ることはありません。

解約と自動更新のオフは、iPhone の「設定」で一番上のお名前(Apple アカウント)をタップし、「サブスクリプション」からいつでも行えます。加入中の方は、本アプリの「せってい」→「fuu. Plus」→「解約・プラン変更」からも同じ画面を開けます。本アプリを削除しても解約にはなりません。

このほか、本アプリ内の「プライバシーポリシーを読む」「利用規約を読む」「お問い合わせ」をタップしたときは、ブラウザでそれぞれのページを開きます。

7. 第三者提供

本アプリが収集する情報はないため、第三者への提供・販売・共有はありません。

本アプリ内の「お問い合わせ」は、Google LLC が提供する Google フォームをブラウザで開きます。フォームで送信されたお名前またはニックネーム(任意)、お問い合わせ内容、メールアドレス(任意)は、お問い合わせへの対応にのみ使用します。

8. お子さまの利用について

本アプリは個人情報を収集しないため、年齢を問わずご利用いただけます。13歳未満の方の個人情報を意図的に収集することはありません。

9. 医療行為ではないことについて

本アプリは、自分の気持ちをながめるためのノートです。疾病の診断、治療または予防を目的としたものではなく、医療機器ではありません。アプリ内に表示される傾向は、利用者自身の記録から算出した参考情報であり、診断ではありません。

心身の不調が続く場合は、医師などの専門家にご相談ください。

10. 本ポリシーの変更

本ポリシーを変更する場合は、本ページ上で改訂版を公開し、最終更新日を更新します。収集する情報の範囲に変更が生じる場合は、アプリ内でもお知らせします。
